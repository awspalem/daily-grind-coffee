# Design & UI

- Treats the admin panel as his primary, most-used surface and wants it feature-rich and complete. Confidence: 0.9
- Prefers admin sections collapsible, with collapsed as the default state. Confidence: 0.9
- Prefers sticky top bar and hamburger menu in the admin app. Confidence: 0.8
- When given the choice for a brand identity, prefers a warm/roastery-aligned palette (copper/amber accents, warm bg/borders, serif display font like Fraunces) over a generic neutral/blue SaaS look — wants the chrome to feel "coffee-forward, not generic SaaS". Confidence: 0.85
- Prefers full visual rebuilds of the admin UI to go in one coordinated pass (tokens + layout + new components like toasts/skeletons/empty-states/command-palette) rather than incremental piecemeal changes. Confidence: 0.85
- Values polished UX primitives in the admin: toast notifications (not alert/confirm), skeleton loading states, empty-state components, sticky top bar with page title + subtitle + breadcrumb, and Cmd+K command palette for navigation. Confidence: 0.9
- Prefers grouped/categorized sidebar navigation with section labels (e.g. Operations, Catalog & Pricing, Economics) over a flat list. Confidence: 0.85
- Wants KPI/dashboard cards to be visually rich: icon chips, semantic color accent strips, delta chips, serif values with tabular-nums, hover-lift shadow — not plain text blocks. Confidence: 0.85
- Optimizes admin for large tablet in landscape orientation. Confidence: 0.7
- Prefers denser information presentation ("more densely packed/presented"). Confidence: 0.7
- Storefront should stay mobile-first/PWA; desktop is a secondary polish target. Confidence: 0.7
- Wants feature parity on daily-use surfaces — when a tool is built for one surface (storefront Maya, customer chat), expects it on the other daily-use surface (admin Maya) too. Treats "storefront-only" and "admin-only" AI features as temporary state. Confidence: 0.8
- Specific pages he uses most (Subscription Plans, Pricing, Orders) get disproportionate polish attention — these are daily-use ops surfaces, not secondary pages. Confidence: 0.8
